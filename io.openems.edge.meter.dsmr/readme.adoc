= Meter DSMR

Reads a Dutch Smart Meter (DSMR 5.0) over its P1 serial port.

The meter pushes a telegram autonomously (~1s on DSMR 5.0). The component reads
the serial stream via jSerialComm, validates the CRC16, parses the OBIS values
and maps them to the `ElectricityMeter` channels (grid: positive = buy-from-grid,
negative = feed-to-grid).

Serial settings: 115200 baud, 8N1.

The `invert` config option multiplies all power values with -1 and swaps
Production and Consumption Energy, e.g. for meters installed in reverse
direction.

Implemented Natures:
- ElectricityMeter
